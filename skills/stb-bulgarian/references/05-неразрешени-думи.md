# Речник на STB · 05 · Неразрешени думи и замени

Версия v0.1 (чернова). Тези думи **не** се използват в STB, защото са многозначни, разговорни, оценъчни или неточни. Всяка има замяна.

## Многозначни глаголи

| Неразрешена | Защо | Замяна |
|---|---|---|
| правя | Прекалено общо | Конкретен глагол: „монтирам", „проверявам", „свързвам" |
| вземам | Много значения | „Използвайте …" или „Извадете …" |
| слагам | Разговорно | „поставям" |
| махам | Разговорно | „премахвам", „демонтирам" |
| изкарвам | Много значения | „изваждам" |
| навивам | Много значения (завъртам, обвивам) | „завивам" или „обвивам около" |
| настройвам | Припокрива се с „регулирам" | „регулирам" |
| осигурявам | Много значения | „проверявам, че …" или „закрепвам" |
| получавам | Много значения | „измервам", „прочитам" |
| давам | Много значения | Конкретен глагол |
| имам | Припокрива се с „има" | „има" |
| тествам | Англицизъм | „изпитвам" |
| забранявам | Командата е забрана | „Не" + повелително |
| разрешавам | — | „Може да …" |
| закачам | Разговорно | „свързвам" |
| пускам | Много значения | „включвам" |

## Оценъчни и неточни думи

| Неразрешена | Защо | Замяна |
|---|---|---|
| бързо, бавно | Неточно | Число със скорост или време |
| малко, много | Неточно | Число |
| често, понякога | Неточно | „всеки 100 часа" или конкретно условие |
| внимателно | Неточно, оценъчно | Конкретно изискване („без удар", „с момент 5 N·m") |
| правилно | Оценъчно | Измерима стойност |
| точно | Неточно | Число с допуск |
| добре | Оценъчно | Измерима стойност |
| наляво, надясно | Зависи от гледната точка | „по часовниковата стрелка", „обратно на часовниковата стрелка" |
| тук, там | Зависи от позицията на читателя | „на фигура 2, позиция 5" |
| сега | Неопределено | Номер на стъпка |
| още, вече | Неопределено | Конкретна проверка |
| някой, никой, нищо | Неопределено | „оператор", „техник", конкретно име |
| повече, по-малко | Само в „повече от", „по-малко от" | Вж. фрази |

## Граматика и стил

| Неразрешена | Защо | Замяна |
|---|---|---|
| но, обаче | Противопоставяне | Две изречения |
| и/или | Двусмислено | „или" (изключващо) или две изречения |
| като | Много значения | „например" не се използва; посочете конкретно |
| така, пък, ето | Разговорни | Не се използват |
| от което, при което | Дълго подчинено изречение | Две изречения |
| бил, била, било (преизказ) | Пренася несигурност | Сегашно или минало свършено |
| би, бих | Условно наклонение | „трябва", „може" |
