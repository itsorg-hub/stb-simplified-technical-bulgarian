# Речник на STB

**Версия v0.1 (чернова) · неофициална публикация**

Речникът съдържа думите, които са разрешени в STB. Всяка дума има **една** част на речта, **едно** значение и пример. Неразрешените думи са в отделен файл със замени.

| Файл | Съдържание |
|---|---|
| [01-функционални-думи.md](01-функционални-думи.md) | предлози, съюзи, частици, местоимения, наречия, фрази за сравнение |
| [02-глаголи.md](02-глаголи.md) | глаголи за инструкции и описания, модални думи |
| [03-съществителни.md](03-съществителни.md) | части, величини, мерни единици, документация, общи понятия |
| [04-прилагателни.md](04-прилагателни.md) | състояние, положение, форма, мерки, изисквания |
| [05-неразрешени-думи.md](05-неразрешени-думи.md) | думи, които не се използват, и замени |
| [domains/](domains/) | пакети по област: механика, електрика, хидравлика и пневматика, ИТ, подемна техника, автоматизация |
| [candidates.txt](candidates.txt) | първоначален списък с кандидати |

## Как са изградени определенията

- Думите са подбрани от списък с кандидати за технически текстове (инструкции, монтаж, чертежи).
- Значенията са написани самостоятелно. Те не са копирани от други речници.
- Многозначните думи са ограничени до една употреба. Останалите значения са неразрешени.

## Ограничения на v0.1

- Определенията не са проверени от езиковеди и не са изпитани върху реална документация.
- Ядрото е около 340 записа, а пакетите по област добавят още около 290. Покритието на всяка област е начално.
- Определенията използват и думи извън речника. В следваща версия определенията трябва да се ограничат до думи от речника.
