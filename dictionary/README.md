# Речник на STB

Тук ще бъде речникът: всяка дума с **една** част на речта, **едно** значение, пример в технически контекст и бележка какво да се избягва.

Статус: в процес. `candidates.txt` е първоначалният списък с кандидати (около 450 думи) по категории. Следващата стъпка е да се определи значението на всяка дума и да се напише собствено определение.

## Формат на запис (планиран)

| Поле | Описание |
|---|---|
| дума | основна форма |
| част на речта | една |
| значение | едно определение, написано самостоятелно |
| пример | изречение в STB |
| избягвай | синоними и други значения, които не са позволени |
