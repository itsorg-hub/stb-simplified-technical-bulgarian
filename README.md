# STB — Опростен технически български

Контролиран български език за технически текстове: инструкции, монтаж, чертежи, спецификации. Цел — всяко изречение да има едно възможно тълкуване.

Вдъхновен от [ASD-STE100](https://www.asd-ste100.org) (Simplified Technical English), но с правила, пригодени за българския език. Проектът не е свързан с ASD.

> **Статус: чернова v0.1.** Правилата не са проверени от езиковеди. Речникът се изгражда.

## Съдържание

- [`docs/rules.md`](docs/rules.md) — правила за писане
- [`dictionary/`](dictionary/) — речник (в процес) и списък с кандидати
- [`scripts/`](scripts/) — скриптове за подбор на думи от свободни източници (PowerShell)
- [`NOTICE.md`](NOTICE.md) — произход на материалите и какво не е включено

Предложения за думи и правила са добре дошли като issues или pull requests. Всяка нова дума в речника трябва да има едно значение и пример.
